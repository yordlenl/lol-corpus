# LoL English 學習站 — 開發規格

Oct 22, 2026 · @피카부Peek-A-Boo

## 給 Claude Code 的工作約定

這份規格要做**兩個獨立的網頁專案**：語料庫和學習 App，讓使用者在 iPad 上用 Apple Pencil 學英語。兩個都從零開始寫，只從 [carefreelove/lol-english](https://github.com/carefreelove/lol-english) 搬幾樣資料和做法過來。請按「開發順序」逐階段實作，每階段結束讓使用者在 iPad 上驗收後再往下。

**使用者背景**

- 不寫程式，透過指揮 AI 開發。請用白話的繁體中文（普通話）溝通，**不要出現簡體字**，使用者讀不懂簡體。
- 看不懂使用者的意思時，先問清楚，不要猜。
- 開發電腦：主力用 MacBook Air M3，寫網頁並用 Safari 網頁檢閱器連 iPad 偵錯。Windows（第 10 代 i7、RTX 2080 Super，裝有台服英雄聯盟）留給展望階段的語音解包與語音辨識。兩台透過 GitHub 同步。
- 學習裝置：iPad + Apple Pencil，**橫向使用**。練習只在 iPad 上進行。
- 有 GitHub 帳號。純自用。

**工作方式**

1. 每個階段先用計畫模式提出做法，使用者同意後才改檔案。
2. 每完成一步，用白話說明改了什麼、在哪裡看效果。
3. 涉及取捨（刪功能、換技術、改資料格式）先問。
4. 介面改動附截圖，和使用者提供的遊戲截圖並排比對（截圖放在 `docs/reference/`）。
5. 每個功能都補上測試。

## 專案目標與整體架構

目標是把英雄聯盟的遊戲文字變成英語教材，並在 iPad 上用手寫練習、按遺忘曲線複習。學英語是唯一目的。

**兩個獨立專案，共用同一份學習紀錄**。兩個專案各自一個 GitHub 倉庫、各自的介面，都發布在 `yordlenl.github.io` 底下。iPad 主畫面上**只放一個圖示**（學習 App），在 App 裡可以切換到語料庫；兩邊在同一個主畫面 App 裡，生詞本與複習紀錄才能共用。

> iPadOS 會給每個主畫面 App 各自獨立的儲存空間，就算網址同源也不共用，所以不能放兩個圖示。這點在 2026-10-22 用 iPad 實測確認過。

- **語料庫**（`yordlenl.github.io/lol-corpus`）：把內容「擺出來看」，外觀像英雄聯盟客戶端。負責產生遊戲資料檔，並提供一個共用模組：資料讀取、卡片元件、生詞本與複習紀錄的存取。
- **學習 App**（`yordlenl.github.io/lol-study`）：練習與複習，外觀像主流背單詞軟體。從語料庫的網址載入遊戲資料和共用模組，不自己重複下載。
- **練習畫面借用語料庫的卡片元件**：同一張裝備卡、同一個技能區塊，加「練習模式」，英文換成空格，其餘照舊。
- **資料庫格式只在共用模組裡定義一次**，兩邊都透過它讀寫，並帶版本號，避免兩個專案寫出不相容的資料。
- **資料存在每台裝置上**：iPad 上收藏的詞，iPad 的學習 App 看得到；在 Mac 上收藏的，iPad 看不到（除非匯出再匯入）。收藏以 iPad 為主，而且收藏和練習都要在主畫面那個 App 裡做；在 Safari 分頁裡收藏的，主畫面 App 看不到。

在主畫面 App 裡切到語料庫收藏的句子，會出現在學習 App 的複習裡。

**三行對照**：英文 / 台服繁中（zh\_TW）/ 簡中（zh\_CN），每一行可在設定中個別開關。介面文字全部繁體。練習的目標語言永遠是英文。

## 資料來源與處理

所有資料都來自公開來源，不做任何逆向工程。lol-english 目前用 Data Dragon 16.19.1，新專案取最新版本；遊戲改版時重新執行建置即可。

**從 lol-english 搬過來的三樣東西**（其餘全部重寫）

1. 346 條選用/禁用台詞（`content/`）：英文、中文學習譯文、原聲網址、逐條來源。
2. ECDICT 詞典的縮減處理，以及哪些詞要標注、哪些跳過的規則。
3. Data Dragon 文字與圖示的下載流程（參考其腳本重寫）。

| 內容 | 來源 | 處理方式 |
| --- | --- | --- |
| 技能、被動、裝備、符文、召喚師技能、皮膚名 | Data Dragon 語言包 en\_US / zh\_TW / zh\_CN | 三個語言包都下載；圖示下載存本機 |
| 裝備合成關係與分類 | Data Dragon `item.json` 的 from、into、tags、depth、maps | 只保留召喚峽谷可購買的裝備；同名多筆要去重（目前列表裡 Abyssal Mask、Archangel's Staff、Ardent Censer 各出現兩次、價格不同，是其他模式的版本） |
| 符文頁結構 | Data Dragon `runesReforged.json`；屬性碎片用 CommunityDragon | 系、排、符文的層級照遊戲 |
| 選用 / 禁用台詞與原聲 | lol-english 的 `content/`（從 lol-english 複製，原始來源 LoL Wiki） | 中文是原作者的學習譯文（簡體）：簡中行照用，繁中行用 OpenCC 字形轉換，兩行都標「學習譯文」 |
| 音標、釋義、詞性、詞形變化 | ECDICT | 中文釋義是簡體，顯示前用 OpenCC 轉成繁體 |
| 同族詞、近義詞 | WordNet | 建置時只抽取遊戲文字裡出現過的詞，做成離線小檔 |
| 複習排程 | [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) | npm 套件 |

**不使用合成語音**：所有練習畫面都不出現合成語音（TTS）。只播放遊戲原聲。

## 第一部分：語料庫

語料庫外觀參考英雄聯盟客戶端（深藍底、金色細邊框），介面從零重寫。圖示用遊戲官方檔案，排版照使用者的截圖手工重建，完成後截圖並排比對、逐步修到接近。

**頁面**

- **英雄**：列表 → 英雄頁，含被動、Q/W/E/R、皮膚名、選用/禁用台詞（可播原聲）。
- **裝備商店**：照遊戲商店排版。左側豎排是屬性篩選，上方橫排是職業篩選，內容按等級分區（起始、基礎、中間件、傳說）。點一件裝備，右側顯示合成樹：上方一排是「可合成」的裝備，該裝備居中，下方是所需材料和價格，再下面是描述。
- **符文頁**：照遊戲符文頁排版，主系、基石、三排小符文、副系、屬性碎片；點符文看描述。
- **召喚師技能**。

**每一頁共通**

- 三行對照，每行可開關。
- 點英文單字查義（音標、繁體釋義）。
- 收藏單字；**新增收藏整句**（一句台詞、一句技能描述），收進句子庫供練習和複習。

## 第二部分：學習 App

選擇路徑簡約、照背單詞軟體的習慣；真正練習時，畫面和語料庫那一頁一樣，只是英文挖空。

**選擇路徑**：首頁 → 類別（英雄、技能、裝備、符文、召喚師技能、選用/禁用台詞、生詞本與收藏）→ 項目 → 模式。

**三種模式**

| 模式 | 適用內容 | 做法 |
| --- | --- | --- |
| 挖空 | 所有有中英對照的句子 | 在語料庫原樣畫面上，挖掉部分單字 |
| 看中寫英 | 所有有中英對照的句子 | 顯示繁中，手寫整句英文；長描述按句子拆開，一次一句 |
| 聽寫 | 只限有遊戲原聲的（目前＝選用/禁用台詞） | 播放鍵＋每個字一條橫線，沒有其他介面元素；可重播 |

選用/禁用台詞同時適用三種模式。皮膚名不出句子題，只能把其中的單字收進單字卡。

**挖空選詞規則**：優先挖生詞本裡的詞，其次挖較難的詞（依 ECDICT 詞頻與考綱標籤）。不挖數字和數值公式、英雄/裝備/技能等專有名詞、常見功能詞（沿用 lol-english 的標註略過規則）。

**手寫輸入**

- 用標準輸入框，讓 iPadOS 的「隨手寫」直接把手寫轉成文字，不另做手寫辨識，也不保留筆跡。
- 點一下空格就放大成手寫區，寫完縮回填入原位，方便 Pencil 書寫。
- 送出前使用者看得到辨識結果，可自行修改；有明確的送出按鈕。

**評分規則**

- 不分大小寫；忽略標點和多餘空白；彎引號與直引號視為相同。
- 其他一律精確比對，拼錯就算錯。
- 送出後逐字標示對錯，並顯示正確答案。
- 有提示鍵（先給首字母，再給答案）；用了提示會影響複習評分。

## 隨機挑戰

隨機挑戰由系統抽題，使用者不能挑。抽題範圍可選：全部內容，或只從生詞本與收藏。

**中→英**：隨機抽句子，題型是挖空或看中寫英。

**英→中**（只有隨機模式）

1. 畫面只顯示一句英文（名字已遮蓋），問「看懂了 / 沒看懂」。
2. 沒看懂 → 顯示繁中翻譯和出處，這句進複習。
3. 看懂了 → 四選一：這句出自哪裡。選項顯示圖示＋繁中名稱。
4. 選錯 → 顯示答案，進複習。選對 → 顯示繁中翻譯，問「我理解的和這個一樣嗎？」
5. 不一樣 → 和「沒看懂」同樣處理。一樣 → 記為答對。

**遮名**：句子裡出現該項目自己的名字（英雄名、裝備名、技能名、符文名、召喚師技能名）時，以「＿＿＿」取代，避免一眼猜中。皮膚不出英→中題。

**干擾項規則**：原則是越精細越好，逼使用者真的看懂細節。

| 句子出處 | 選項類型 | 干擾項怎麼抽 |
| --- | --- | --- |
| 裝備描述 | 裝備 | 同一等級（depth）＋至少一個相同屬性標籤；湊不滿三個時，放寬為只看同等級 |
| 技能描述、選用/禁用台詞 | 英雄 | 同職業標籤的英雄 |
| 符文 | 符文 | 同一排：基石對基石，小符文對同排小符文 |
| 召喚師技能 | 召喚師技能 | 全部召喚師技能當選項池 |

## 複習排程與生詞本

複習用 ts-fsrs（FSRS 演算法）排程，評分由練習結果自動決定，使用者不用自己按「記得 / 忘了」。

**卡片類型**：單字卡、句子卡。

- 單字卡複習：看繁中釋義，手寫英文單字。
- 句子卡複習：隨機用挖空或看中寫英；有原聲的也可能出聽寫。

**卡片來源**：語料庫收藏（單字或整句）、練習寫錯的題目、隨機挑戰中按「沒看懂」/選錯/「不一樣」的句子，全部自動進複習。

**自動評分對應**

| 練習結果 | FSRS 評分 |
| --- | --- |
| 一次寫對 | Good |
| 用了提示才寫對 | Hard |
| 寫錯、沒看懂、選錯、理解不一樣 | Again |

**首頁顯示**：今日待複習數、今日新學數（預設 20，可調）、連續學習天數、正確率、最常錯的詞。

**生詞本頁**：列出所有單字卡與句子卡，可搜尋、刪除、匯出。

## 查詞與詞彙擴充

點一個英文單字，顯示音標、繁體釋義、詞性、詞形變化、同族詞與近義詞，以及一鍵複製提問。

- **詞性、詞形變化**：來自 ECDICT。
- **同族詞、近義詞**：來自 WordNet，例如 decide / decision / decisive 並列對照。
- **複製提問按鈕**：每個詞都有，辭典沒收錄的詞要特別醒目。按下後把一段提問複製到剪貼簿，使用者自己貼到 Claude App。範本：

```
請解釋英文單字「{word}」的構詞（詞根、字首、字尾）和詞性，列出同族詞與近義詞，並用英雄聯盟的情境造兩個例句。它出現在這句話裡：{sentence}
```

第一版不在網頁裡直接呼叫 AI。

## 儲存、離線與部署到 iPad

學習紀錄只存在 iPad 本機，兩個網站都放在使用者自己的 GitHub Pages。iPad 用 Safari 打開學習 App 後「加入主畫面」，只加這一個。不做原生 App，不用 Xcode；不需要每日複習提醒推播。

**儲存**

- 生詞本、收藏、複習紀錄存在 IndexedDB，啟動時呼叫 `navigator.storage.persist()` 申請持久儲存。
- 主畫面上只有一個 App。學習 App 的 manifest 範圍設為整個 `yordlenl.github.io`，所以切到語料庫時仍在同一個 App 裡；在語料庫按「加入主畫面」，加入的也是學習 App。兩個專案各自有自己的 service worker，範圍限定在自己的路徑。Safari 會清掉一般網站「7 天沒打開」的資料，主畫面網頁 App 不受這條限制。
- 設定頁提供一鍵匯出 / 匯入 JSON 備份。
- 文字、圖示、詞典離線可用；原聲需要聯網（從 LoL Wiki 串流）。

**部署**

- 在使用者的 GitHub 建兩個新倉庫（例如 lol-corpus、lol-study），下載到 Mac 開發。
- 兩個倉庫都用 GitHub Pages 發布，網址公開但不宣傳。
- 遊戲改版時：重新執行資料建置，再重新部署。

**畫面尺寸**：iPad 橫向為主要尺寸（例如 1180×820、1366×1024）。語料庫也要能在電腦瀏覽器正常使用。

## 開發順序與驗收標準

分七個階段，學習功能排在語料庫 UI 之前，因為學英語是主要目的。每階段的驗收都在 iPad 上由使用者確認。

1. **準備**：在 GitHub 建兩個倉庫並下載到 Mac、安裝 Node.js、兩個專案各發布一個空白首頁，設定好 Mac Safari 網頁檢閱器連 iPad。
   - 驗收：iPad 能打開兩個網址；主畫面只加一個 App，從它切到語料庫仍在同一個 App 裡，兩邊讀得到彼此的資料。（2026-10-23 完成）
2. **語料庫資料與基本頁面**：下載三語資料與圖示，搬入台詞與詞典並轉繁體，做出能瀏覽的基本頁面（三行可個別開關），完成共用模組。
   - 驗收：任何頁面都沒有簡體介面文字；三行對照正確顯示。（2026-10-23 完成）
3. **學習 App 骨架與複習**：首頁、生詞本、收藏整句、ts-fsrs 排程、匯出匯入、PWA。
   - 驗收：在 iPad 主畫面 App 裡切到語料庫收藏的詞，按排定的日子出現在學習 App 的「待複習」；匯出再匯入後紀錄完整。
4. **練習模式**：挖空、看中寫英、聽寫，手寫輸入與評分。
   - 驗收：用 Pencil 在三種模式各完成一題，對錯判定符合評分規則。
5. **隨機挑戰**：中→英、英→中五步流程、遮名、干擾項規則。
   - 驗收：連做 20 題，沒有一題的答案名字出現在題目裡，干擾項都符合規則。
6. **語料庫 UI**：裝備商店（含合成樹）、符文頁，照遊戲截圖重建。
   - 驗收：和 `docs/reference/` 的截圖並排比對，使用者認可。
7. **查詞擴充**：詞性、詞形變化、同族詞、近義詞、複製提問按鈕。
   - 驗收：未收錄的詞能一鍵複製提問，貼到 Claude App 內容正確。

## 不在第一版範圍（展望）

以下三項第一版不做，但資料格式要先預留，以後只是加資料，不用大改網頁。

1. **遊戲聊天術語**：縮寫、常用溝通句子，讓使用者能像 LEC / LCS 外援一樣和隊友溝通。參考 [typethis.lol](https://typethis.lol) 按遊戲階段分類的做法，內容自行整理。
2. **韓文漢諺混寫（第四行）**：用 Data Dragon 的 ko\_KR 語言包；漢字詞以 ruby 標注諺文（像日文假名注音）。韓服原文是純韓文，漢字轉換要 AI 處理＋人工檢查。
3. **英雄局內全台詞**：英文來自 LoL Wiki 各英雄的 Audio 頁；台服繁中、簡中官方配音用 [lol-audio-unpack](https://github.com/Virace/lol-audio-unpack) 從使用者本機的台服客戶端解包（以 `-locale` 參數切換語言下載語音包），按遊戲事件配對，再用 Whisper 在本機 RTX 2080 Super 上把語音轉成文字。先用一隻英雄試驗配對準確率，不用 AI 翻譯。

**台詞資料格式（現在就照這個存）**

| 欄位 | 說明 |
| --- | --- |
| 英雄 | 英雄 id |
| 語音組 | 原版或皮膚語音組 |
| 情境 | 選用、禁用、首次移動、擊殺等遊戲事件 |
| en / zh\_TW / zh\_CN / ko | 各語言文字，ko 先留空 |
